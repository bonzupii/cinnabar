03 Wordmark Schibsted Grotesk 800, caps, drawn C
INNABAR
Base

Schibsted Grotesk 800, all caps. One weight only; no italic, no lower case, no outline.

The C

Replaced by the drawn letter. The only curved character in the word becomes the only one without curves — and the only one that carries colour.

Fit

The C's arms match the I's crossbar weight and sit at the word's own ink gap, 0.071 em. Tracking −0.035 em above 64 px.

Never

Do not set the C in the foundry's own glyph. The drawn letter is the mark; substituting it removes the identity.

INNABAR INNABAR INNABAR INNABAR

Tracking opens as size falls: −0.035 em above 64 px, −0.03 em to 32 px, −0.02 em to 16 px, −0.005 em below. Minimum wordmark height 12 px; below that, the mark alone.

# linear handles are consumed exactly once on every path
use Collections.vec_new
use Collections.vec_free
 
const BAD_NEW: I64 = 1
 
pub fun main() impure I64
val vec = match vec_new[I64]()
Ok(v) => v
Err(error) => return BAD_NEW
end
 
val view = vec_view(&vec)
vec_free(vec) # handle consumed
return 0
end

Linear types

Consuming a handle

A native handle owns a resource. The borrow checker walks every path through the function and requires the handle to be consumed on each one, exactly once. Consuming it twice is an error; not consuming it is an error.

14 Misuse Six things that break the system
Do not recolour the block. It is vermilion, or it matches the letter — nothing else.
Do not rotate. It is a letter; it sits upright.
Do not stretch. Scale proportionally or not at all.
